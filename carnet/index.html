    Apparence

    Gardez-le à l’abri

    Sur iPhone, Safari efface les données d’un site resté fermé pendant sept jours d’utilisation. Ajoutez le carnet à l’écran d’accueil : bouton Partager, puis « Sur l’écran d’accueil ». Installé, il n’est plus concerné.

    Installé sur l’écran d’accueil

    Le carnet garde vos données tant que vous l’utilisez. Un export de temps en temps reste la meilleure sauvegarde.

    L’export est un fichier JSON avec tous vos cafés et toutes vos tasses ; copié, il se colle dans une note. L’import ajoute ce qui manque, sans rien écraser.
